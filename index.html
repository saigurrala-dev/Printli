Printli Platform Architecture

Central Thesis: The platform is an intelligent bridge connecting digital customer orders and physical print/document operations.

💡
Architecture Philosophy: The Cloud decides WHAT to print, how to route, price, calculate dynamic ETA, and audit. The local shop Print Station decides HOW to feed jobs silently to OS print queues with zero network lag via aggressive prefetching.

Payment Flow with Idempotent Webhooks

Why this matters: Payment gateways retry callbacks under latency. Using strict idempotency keys guarantees no double charging or duplicated print orders occur.

GW-->>Cu: UPI payment screen
GW->>API: Webhook payment success
API->>DB: Event already processed?
alt Duplicate
 API-->>GW: 200 OK, ignore
else New

 API-->>GW: 200 OK
end
